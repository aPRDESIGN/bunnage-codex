# Bunnage（仮）ゲーム仕様

本書はゲーム全体の原則を定める。操作の詳細は [UX_SPEC.md](UX_SPEC.md)、初期デモの範囲は [DEMO_V01_SPEC.md](DEMO_V01_SPEC.md) を参照する。

## コアコンセプト

**「投げて、壊して、片付けない。」**

現実では物を投げたり壊したりすると、破損や片付けが発生する。本作ではスマートフォンを握ったまま腕を振り、ゲーム内の物を投げる疑似体験を提供する。

目的は敵を倒すことではなく、**思いきり物を投げる身体的な解放感と、物が飛ぶ・ぶつかる・壊れる爽快感**。人間・NPCは登場させず、人を傷つける・攻撃するニュアンスにしない。

## ゲーム全体の原則

| 項目 | 方針 |
| --- | --- |
| 想定端末・画面 | iPhone、縦持ち、縦画面9:16 |
| 視点 | 一人称、プレイヤー位置固定 |
| 移動 | 歩行なし、ステージ探索なし |
| 登場対象 | 人間・NPC・敵なし |
| 攻略要素 | HP・スコア・勝敗・ミッション・時間制限なし |
| 投擲アイテム | 個数制限なし、同じアイテムを無限補充 |
| 終わり方 | 満足したらユーザー自身がアプリを閉じる。ゲーム内終了ボタンは不要 |

攻略ではなく「投げる」ことを中心にする。ユーザーに頑張らせず、全力で振らなくても十分な速度と破壊を得られるようにする。

## コアゲームループ

1. アイテムを選ぶ。
2. 画面をHOLDする。
3. スマートフォンを握ったまま振る。
4. 振り切りを自動検出する。
5. ゲーム側で自動リリースする。
6. アイテムが飛び、衝突する。
7. 壊れる・潰れる・凹む・跳ねるなど、物に応じた反応が起きる。
8. 同じアイテムを自動補充し、また投げる。

別のアイテムを選ぶまで選択を維持する。投擲成立後、アイテムが手元を離れてから0.3〜0.5秒程度を目安に同じアイテムを自動補充する。この時間は固定仕様ではなく実機で調整する。補充と、一度画面から指を離したことの確認を経て、次のHOLDを受け付ける。指を離さない限り次の投擲に入らず、腕を戻す動作の誤検出を防ぐ。

振る前に指が離れた場合はHOLDを解除し、投げずにアイテムを手元に残して、HOLDパルスを通常状態に戻す。振り切り検出による投擲成立後の指離れは、成立した投擲結果に影響させない。

## 投擲の思想

- 完全な物理再現より、**「自分が投げたと思った方向へ飛んだ」**という納得感を優先する。必要に応じてゲーム側で補正する。
- カメラ方向を基準に、振った方向・強さ、端末の向き、回転を使って投擲方向と強度を推定する。
- 特に正面・左・右・下方向への投げ分けを重視する。
- 強度の概念はLIGHT / NORMAL / HARD程度。ゲーム画面には表示しない。
- NORMAL程度で十分な勢いと破壊を得られるようにする。一定以上の強さには上限を設けてもよい。
- 端末を投げつけるような腕の動作をゲーム内投擲へ変換するが、**実際のスマートフォンは絶対に手から離さない**。
- 投擲検出・振り切り・方向補正・強度等の具体的な閾値は現時点では固定しない。ハードコードせず、後から容易に変更・比較できるパラメータとして管理し、iPhone実機テストで調整する。

## 破壊と音の思想

**リアルに見えるが、現実より気持ちよく壊れる。**

- 物理挙動：リアル寄り。
- 破壊判定：少し甘め。
- 演出：少し大げさ。
- NORMAL程度の投擲で十分な爽快感を得る。
- 物ごとに音を変え、衝突・破壊後の余韻も重視する。

| 物 | 音のイメージ |
| --- | --- |
| グラス | シュッ → パリーン → カラカラ |
| 卵 | シュッ → ベチャッ |
| 缶 | カンッ → カラカラ |

## 投げた結果を残す

グラスの破片、卵の汚れ、凹んだ缶、倒れた物をその場に残す。投げ続けるほど、最初は普通だったキッチンが徐々にめちゃくちゃになっていくことを体験の一部とする。

性能維持のため、静止した破片の物理演算停止、静的オブジェクト化、非常に細かい破片の簡略化、必要に応じた破片表現の統合を許可する。ただし、**プレイヤーから見て「壊した結果が勝手に片付いた」と感じる処理は禁止**。同じステージでのプレイ中は、ユーザーが「きれいにする」を実行するまで、見た目の散らかった状態を維持する。ステージ離脱後の扱いは従来のDemo仕様に従う。

可能であれば「投擲物が小物に当たる → 小物が倒れる → 別の物に当たる」といった物理連鎖を許可する。狙った対象だけが反応するゲームにはしない。キッチンそのものの骨格は完全破壊しない。

片付けは義務や進行条件にしない。ユーザーが希望した場合のみ、メニューの「きれいにする」で初期状態に戻せる。Demo v0.1ではステージを離れた際の状態保存は不要。

## 世界観

Demo Stage 01は日本の庶民的なキッチン。公営住宅や少し古めの一般的なマンションにありそうな、少し使用感と生活感のある空間とする。高級住宅・モデルルーム・おしゃれなキッチンにはせず、極端に汚くもしない。

生活感は調味料、食器、タオル、家電、ゴミ箱、収納用品、日用品、メモ等で表す。人物、NPC、観葉植物、子どもを想起させる物、キャラクター雑貨、玩具、ファンシー雑貨は配置しない。
